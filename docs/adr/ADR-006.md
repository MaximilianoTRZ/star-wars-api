# ADR-006: Spring Boot 4.1.2 con Java 21

## Estado

Aceptado

## Contexto

El proyecto usa Java 21. Hay que elegir una versión de Spring Boot con soporte OSS activo y compatible con las librerías de terceros (springdoc, Resilience4j, WireMock).

## Decisión

Usar Spring Boot **4.1.2** con Java 21.

| Línea | Estado al 12/11/2026 | Fin de soporte OSS |
|---|---|---|
| 3.5.x | Sin soporte OSS | 30/06/2026 |
| 4.0.x | Soportada, por poco tiempo | 31/12/2026 |
| **4.1.x** | **Última estable (4.1.2)** | **31/07/2027** |
| 4.2.x | Release candidate; GA el 19/11/2026 | 31/12/2027 |

4.2 todavía no es GA. El upgrade queda como próximo paso.

## Compatibilidad verificada

Starters renombrados en Boot 4 respecto a Boot 3:

- `spring-boot-starter-web` → `spring-boot-starter-webmvc`
- `spring-boot-starter-aop` → `spring-boot-starter-aspectj`
- Los starters de test se separaron por tecnología: `spring-boot-starter-webmvc-test`, `-security-test`, `-restclient-test`
- `@MockBean` fue eliminado; se usa `@MockitoBean`

Terceros:

- **springdoc 3.1.0**: compatible con Boot 4 / Spring MVC. La línea 2.x es solo para Boot 3.
- **resilience4j-spring-boot4 2.4.0**: módulo específico para Boot 4. El BOM de esa versión no lo incluye, se declara con versión explícita.
- **wiremock-standalone 3.13.2**: `wiremock-jetty12` choca con el Jetty 12.1 que gestiona Boot 4 (ADR-012).

## Alternativas descartadas

- **Spring Boot 3.5:** sin soporte OSS desde el 30/06/2026.
- **Spring Boot 4.2.0-RC:** no es una versión GA.

## Consecuencias

- El proyecto usa los nombres de starters de Boot 4 desde el inicio.
- `resilience4j-spring-boot4` lleva versión explícita en el `pom.xml`.
- Soporte OSS hasta el 31/07/2027.
